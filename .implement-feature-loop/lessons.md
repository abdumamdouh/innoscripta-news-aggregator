- 2026-08-08: Item 1 (App shell + design system) stalled at the e2e gate — `mcp__playwright-chrome__browser_navigate` to `http://localhost:3100` failed with `ws://localhost:9222/devtools/browser 403 Forbidden`, retried once, same result. The mandated browser MCP needs a Chrome instance already reachable on the devtools port; nothing in the loop starts/attaches one, so any environment where that port isn't pre-opened will block every e2e gate the same way, regardless of the item under test. The dev server itself came up fine (`npm run dev -- --port 3100 --strictPort`, confirmed serving via Vite log). Static review + code review + acceptance all passed on inspection alone. Fix for next run: verify the playwright-chrome devtools port is reachable *before* starting the loop (or switch the mandated browser MCP), since a per-item retry cannot fix an environment-level connection problem — don't burn iteration budget retrying browser_navigate again for the same root cause.
